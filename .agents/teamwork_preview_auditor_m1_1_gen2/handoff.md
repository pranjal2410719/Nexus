## 2. Logic Chain

1. **GitHub API Contract Satisfaction (Observation 1.1, 1.2)**:
   - For new files: 404 response causes `fetchCurrentFile` to return `sha: undefined`. In `makeSingleCommit`, omitting `params.sha` allows GitHub's REST API `createOrUpdateFileContents` to create the file with HTTP 201 without error.
   - For existing files: 200 response yields the current blob SHA regardless of file size (including 0-byte empty files). In `makeSingleCommit`, passing `params.sha = sha` satisfies GitHub's requirement for updating existing files, avoiding HTTP 422 `"sha" wasn't supplied` errors.
2. **Elimination of Concurrency / Chaining Conflicts (Observation 1.3, 1.4)**:
   - Sequential batch commits require each subsequent commit to know the new blob SHA produced by the prior commit. By calling `fetchCurrentFile` on each iteration of `makeBatchCommits`, the commit loop dynamically receives the updated SHA, preventing HTTP 409 Conflict.
